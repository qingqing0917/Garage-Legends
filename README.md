# Garage Legends · 极速车库：造车人生

完整的可玩流程：**修车或组装 → 车辆改装 → CS 参数调校 → 亲自驾驶参加比赛 → 领取奖金、带着车损回工坊维修。**

## 运行

macOS 双击 **启动游戏.command**。它使用本机 Node.js，启动只监听本机的服务器，并打开默认浏览器。`dist/` 已包含可运行构建，字体、车辆、赛道和音效均在本地，无需注册或下载额外车辆资源。

也可以在本目录运行：

```sh
node server.mjs
```

默认地址为 `http://127.0.0.1:5173/`，端口占用时会顺延。以终端实际打印的地址为准。需要支持 WebGL 2、启用硬件加速的现代桌面浏览器。关闭终端或按 Ctrl+C 结束服务器。

开发、测试与构建（Node.js 22.12+）：

```sh
npm install
npm run dev
npm test
npm run build
```

## 开始游戏

顶部有五个可以直接切换的地点：**修复工坊、车辆改装、CS 调校、赛道竞速、车库生活**。比赛前可选择北郊环线或云岭盘山路，并为三位对手分别搜索和选择车型；车库生活中可以步行、驾驶、探索街区和景点。

### 车型收藏馆：5,946 条目录车型

点击车名下方 **更换车型** 打开收藏馆。本版包含 1,828 条跑车、2,709 条轿车和 SUV 等目录，以及新增 1,409 条两厢车、旅行车、皮卡、MPV、厢式车和其他车型，共 **5,946 条目录车型、604 个品牌**，另有 R-86 和 AERO S1。入口的 ∞ 表示目录可继续扩充，并非声称车型无限或收录全球所有车。同车系不同年份或特殊版本可能分别列出。

- 支持中文品牌名、英文品牌和车型关键词组合搜索，例如「法拉利 F40」「吉普 Wrangler」；支持轿车、SUV 和越野车快捷筛选，以及品牌、类别、车门和年代等筛选，每页 12 款。
- 免费交换，不扣钱、不推进时间。资金、机械部件状态、已有性能改装、CS 调校、每日补助和比赛记录随项目保留。每辆车的车漆、修复与涂刷进度单独保存。
- 26 种简化设计语言涵盖跑车、轿车、SUV 与越野车：高顶、后排侧窗、行李架、越野胎和备胎等特征按类别显示。热门 20 款跑车细化轮廓、灯组和进气口；同车系仍共享设计语言，性能数值为游戏设定，并非逐车精确复刻。
- 720S 增加泪眼灯窝、侧进气、后部发动机盖和中置动力总成。部分车型显示 V 形发动机或电驱总成；这些是简化的游戏表现，动力总成类型和结构并非逐车型原厂配置。打开引擎盖时，迈凯伦的前盖与后舱盖一起打开，维修标记随动力总成移动。
- F40 使用方楔车身、升起式灯罩和桥式大尾翼；Revuelto 使用低矮锐角、Y 形灯和六边形进气口；Chiron 使用马蹄格栅、双色后侧与 C 形侧环；Huayra 使用四眼灯、长杆镜和中置四出排气；918 Spyder 使用圆润车身、椭圆灯和顶置排气。
- 收藏馆直接显示对应程序化 3D 模型的默认外观预览（原有 R-86 保留侧影），车库使用玩家保存的车漆和车顶状态。可搜索设计关键词，例如「方楔经典」「马蹄格栅」「中置四出排气」。
- 工坊、改装、CS 和比赛使用所选车型。机械零件、涂刷、车损、升级与自动过弯继续可用；换车本身不会修复原有机械故障。
- 车库仅保留当前选择的生成模型，换车释放旧模型资源。收藏馆按可见卡片逐帧生成 3D 缩略图并释放预览模型，最多缓存 96 张图片；筛选、翻页或关闭会取消旧预览队列，避免预先加载上千辆车。原有存档和选择保持不变。
- 比赛中或发动机运行时不能换车。刷新保留已选车型，可以随时换回原车型。

资料抓取时间为 2026-11-07。新增条目来自 Wikipedia 的 SUV 表与轿车 / 运动轿车分类，按名称去重；轿车分类未提供年份的条目标为「年代未核实」。越野分类由名称和类别关键词推断，不是官方越野能力认证。每张车型卡都能打开资料来源；详细归属及导入审计见 `SOURCES.md`。

### 特殊车门与开合车顶

车名下方可以直接打开 / 关闭车门；支持敞篷的车型还会出现 **切换敞篷 / 切换有顶篷**。这些操作免费，不推进时间，也不改变性能改装和机械状态。

- 4 种特殊机构：鸥翼门向两侧上翻（如 SLS AMG、Huayra），剪刀门向前上翻（如 Revuelto），蝴蝶门向外上方打开（如 McLaren 720S），旋翼门先外旋再上翻（如 Koenigsegg Jesko）。其余目录车型使用侧开门；原有 R-86 继续保留固定车身。
- **AERO S1** 免费升级为剪刀门 + 可开合车顶，直接搜索「AERO S1」即可体验两项功能。
- 本版提供 10 条鸥翼门、20 条剪刀门、54 条蝴蝶门、15 条旋翼门车型及 681 条可开合车顶车型（包括 AERO S1）。收藏馆新增「车门 / 车顶」筛选、快捷按钮和车型标记；也可搜索「鸥翼门」「欧翼门」「敞篷」。
- 门板、侧窗、后视镜一起运动，车身有真实的车门开口与座舱；鸥翼门带动车顶两侧。门板与固定车身共用原来的喷漆区域，保持已完成的车漆与修复进度。
- 开篷时侧窗降下，分段硬顶折叠并收起；合篷时恢复车顶、后窗和侧窗。**每辆车分别记住车顶状态**，换车、刷新、去改装中心和 CS 店后仍然保留。选中「车顶」喷漆面板会自动合篷，方便施工。
- 开合车顶前自动关门；点火、切换地点和进入赛道时也会关闭展示车门。比赛用车保留所选开篷 / 合篷状态，比赛中无法操作车门或车顶。切换驾驶舱视角不会让已收起的侧窗重新出现。
- 车门机构及折叠车顶为简化的游戏表现，不是逐款车型的原厂机械复刻。源目录合并了 Coupé / Roadster 的 SLS、300 SL、Huayra 条目时，使用经典鸥翼门轿跑形式；已有独立敞篷条目使用可开合车顶。

### 1. 修复工坊

- **废车修复**：启动资金 30,000 CR，购车花费 1,800 CR，剩余 28,200 CR。
- **从零组装**：启动资金 50,000 CR，底盘和白车身花费 5,500 CR，剩余 44,500 CR。
- 点击部件列表顶部的 **一键整备**，可按正常零件与维修价格一次修好并装齐所有机械部件，恢复至 100%。确认界面显示费用、剩余余额和工时；立即完成，无需现实等待。也可以继续手动维修。
- 点击部件清单或车上标记，执行「拆下 → 检修 → 装回」。缺失的部件可以购买安装。
- 车身修复按「除锈 → 打磨 → 喷漆」进行。按住左键涂刷，右键旋转，滚轮缩放。七块面板独立记录实际涂刷进度；支持七种车漆。
- 八个机械部件全部安装、健康度达到 70% 即可点火、前往 CS 店。外观修复不是参赛门槛，可自行决定先修到什么程度。
- 游戏中的工作日为 08:00–20:00，拆装、维修和涂刷推进时间。首日领取启动资金，次日起每天可领 100,000,000 CR；免费整理车库推进 6 小时。
- 底部 **休息到次日 +1 古戈尔 CR** 可立即跳到次日 08:00，每次获得 10 的 100 次方 CR。每日补助仍可单独领取；可连续休息。工坊、改装和 CS 店均可使用，发动机运行或比赛中不可休息。大额余额以科学计数法显示，内部精确记录。

### 2. 车辆改装

独立的「车辆改装」界面提供六类硬件：进排气与 ECU、涡轮增压、运动轮胎、高温刹车、赛用悬挂、轻量化。**每类等级上限均为 100,000,000（1 亿）级。**

- 输入目标等级，或点击 +1 / +10 / +100 / +1,000 / +1,000,000 级。也可以「选择可购最高级」或「预览 1 亿级」。输入时实时预览功率、扭矩、抓地、制动、质量和转向响应，保留输入焦点；空值、小数和超出上限的值会提示并禁止安装。预览已计入车辆磨损，不扣款。
- 明确显示本次费用、工时、余额和资金差额；点击「安装」才扣费并保存。L1–L3 的价格与效果保持原样；L4 起每级价格固定为该类别原 L3 的价格，只累计支付尚未购买的等级。批量选择与扣费不会逐级循环。每级消耗 1.5 小时，一批最多 12 小时游戏时间，现实中立即完成。
- 完好 R-86 原车 118 hp、AERO S1 原车 228 hp；引擎三级累计 +80 hp，涡轮三级累计 +95 hp，两项均为 L3 时 R-86 为 293 hp，AERO S1 为 403 hp。旧版引擎 L1/L2 的效果与价格保留。
- L1–L3 的轮胎提升牵引与过弯抓地；悬挂提升抓地及转向响应；L3 刹车提升 35% 制动力，L3 轻量化减重 225 kg。L4–1 亿级采用逐渐放缓的连续强化曲线，继续增加动力、抓地、刹车与转向响应、降低质量。满级额外引擎 +240 hp、涡轮 +360 hp、轮胎抓地 +0.4、悬挂抓地 +0.1 / 响应 +0.25、刹车 +45% 基础制动力，轻量化在 L3 质量基础上再减 18%；不会出现负车重或无效数值。
- 安装要求机械检查通过，并且发动机已关闭、当前没有进行中的比赛。套件、调校和损伤都会真实影响比赛，旧改装自动保留，已购等级不重复收费。

### 3. CS 参数调校

调校提供「均衡街道、加速优先、弯道优先、高速巡航」四套预设，可以进一步调整：

- **终传齿比**：3.2–4.8，改变车轮驱动力、换挡时机及高速转速。
- **悬挂硬度**：25–85%，改变转向响应和前后轮侧向稳定性。
- **前轮制动力分配**：50–75%，改变制动效率及重刹时的后轮稳定性。
- **胎压**：24–36 PSI，改变轮胎抓地力。

选择预设、拖动滑杆时可以预览性能，点击 **应用调校** 后才会保存；费用 200 CR，消耗 1 小时。重复应用相同已保存方案不收费。面板显示的极速是估算值。

### 4. 赛道竞速

**自动过弯默认开启**。发车后不必按键，系统会沿赛道自动转向、提前减速、出弯加速，也会跟随前车减速。开关位于比赛右上角，按 `F` 可随时切换，设置会随存档保留。

- 辅助开启时增加 18% 有效抓地，并启用牵引与车身稳定辅助；真实的改装、磨损、碰撞和圈数计算仍然有效。
- `S` 或屏幕刹车可停车，松开后继续自动行驶；辅助刹停不会自行倒车。
- 按住 `A/D` 或方向按钮可暂时接管转向，松开后恢复循迹；空格仍可使用手刹。手动干预仍可能造成碰撞。
- 关闭辅助恢复原本的手动驾驶及车辆抓地参数；`W/S` 控制油门、刹车与倒车，`A/D` 转向。
- 旧存档首次升级自动过弯时默认开启，新项目也默认开启；该辅助保留已有损伤、改装和调校。

先通过机械检查、完成至少一项性能改装、保存一套 CS 调校，再点击 **发车**。

- 北郊环线约 638 米；云岭盘山路约 692 米，有上坡与下坡。比赛共 2 圈，对阵 3 位 AI。
- AI 和玩家使用相同的基础车辆动力学。玩家亲自操作自己所选的车型，车身外观、性能套件与调校会带入赛道。
- 驾驶使用简化动态自行车模型，包括发动机扭矩、五速自动换挡、轮胎侧偏、抓地极限、制动、惯性和路外阻力。辅助会自动规划弯速；手动驾驶时高速入弯需要减速，猛打方向可能失去抓地力。这是可玩的驾驶原型，尚非专业车辆仿真器。
- 支持车后跟随及驾驶舱视角，具有速度、挡位、转速、圈数、名次、比赛计时、车辆状态和小地图。
- 碰撞护栏或对手会损伤发动机、散热器、传动或轮组，损伤会影响本场性能并保存到工坊。部件低于参赛标准时，需要修好再比赛；严重损坏会退赛。
- 没有报名费。第 1–4 名奖金分别为 **8,000 / 6,000 / 4,000 / 2,500 CR**。奖金只结算一次；主动退赛、严重损坏退赛或刷新中断比赛不会发奖。
- 比赛进入时消耗 3 小时游戏时间。切换标签页或窗口失去焦点会自动暂停，返回后点击继续。
- 有赛道进度校验，逆向行驶不增加圈数，救援不会赠送赛程进度。

## 操作

| 场景 | 操作 |
|---|---|
| 工坊 | `1–4` 切换拆装、除锈、打磨、喷漆 |
| 工坊 | `H` 开关引擎盖，`R` 复位视角，`空格` 点火/熄火 |
| 比赛 | `F` 切换自动过弯 / 手动驾驶（默认自动） |
| 比赛 | `W` / `↑` 加速；辅助开启时自动控制安全速度 |
| 比赛 | `S` / `↓` 刹车；辅助开启时保持停车，手动模式可倒车 |
| 比赛 | `A/D` 或 `←/→` 转向；辅助开启时松开恢复自动 |
| 比赛 | `空格` 手刹，`C` 切换车后/驾驶舱 |
| 比赛 | `R` 将车辆救回已行驶到的赛道位置，计时增加 5 秒 |
| 比赛 | `Esc` 暂停或继续；也可以按住屏幕上的转向与踏板按钮 |

比赛进行中切换地点会先询问是否退赛。保留同一个项目即可反复「调校—比赛—维修」。开始新项目会清除当前存档，需在对话框中确认。

## 存档与版本

0.1 至 0.10 的存档继续保留已有余额、部件、原有改装、调校和涂刷进度。0.5 会按新旧启动资金差额一次性补款：标准废车路线补发 **22,000 CR**，从零组装路线补发 **32,000 CR**，无需重新开始。刷新不会重复发放，新存档不会额外补款。进度保存在当前浏览器、当前地址的 localStorage 中；更换浏览器或端口会使用不同存档。没有账号、云存档或数据上传。

当前版本提供 5,946 条公开目录车型及两辆原创车型、一条赛道和四车比赛。车辆、场景、材质与声音仍为原型资产，后续可以继续打磨写实画面、驾驶反馈和更多车型/赛道。
